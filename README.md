# AI-code-player-from-AI-chat
Paste AI chat output → instant project. Zero-server workbench with live preview &amp; local save, hosted on GitHub Pages.Please copy and paste the answer generated by the AI. (You don’t need to extract just the code or omit the explanations—just copy the entire response.)
Even if you have the AI modify part or all of the code, simply copy and paste the entire response as is, and only the relevant parts will be automatically updated!
Please use it via the link below:[https://wakana-code.github.io/AI-code-player-from-AI-chat-not-codex-/](https://wakana-code.github.io/AI-code-player-from-AI-chat/)
# how to use
## 1. First paste this prompt to ur favorit AI!
#### Prompt
```prompt

When outputting code, you MUST strictly follow the format below.

[General Rules]
- You may freely write explanations and commentary, but ONLY outside of the "#### MANIFEST", "#### FILE:", and "#### PATCH:" blocks (the tool parses only these blocks and ignores all other text)
- Omissions such as "the rest is the same" or "(snip)" are strictly forbidden

[A. When creating a new project]
1. Start with a manifest:
#### MANIFEST
```manifest
PROJECT: project-name (alphanumeric characters and hyphens only)
TYPE: static
FILES:
- index.html
- css/style.css
Output every file in full using exactly this format:
FILE: path
language

(full content of the file)
[B. When modifying existing code] Do NOT re-output entire files. Instead, output each change using the following PATCH format:

PATCH: path/of/target/file
old

(the code BEFORE the change — copy it character-for-character from the original code, including indentation and blank lines)
new

(the code AFTER the change)
PATCH rules:

The old block must be an EXACT copy of code that actually exists. Do not change.
The old block must be long enough to be uniquely identifiable within the file (include surrounding lines so it does not accidentally match other locations)
One change = one PATCH block. For multiple changes, output multiple PATCH blocks
When adding a new file, use the "#### FILE:" format with the full content, not a PATCH
When rewriting an entire file, you may also use the "#### FILE:" format (the whole file will be replaced automatically)
[Path Rules]

Relative paths only. Never start a path with / or ../
The entry point of a static site must always be index.html
[C. Adding / Removing Code and Deleting Files]
- To ADD code to an existing file, also use the PATCH format: include the existing code around the insertion point in the old block, and write "the same code + the new lines" in the new block
- To REMOVE code, also use the PATCH format: put the range containing the lines to delete in the old block, and write the remaining code without those lines in the new block (if nothing remains, the new block may be empty)
- To add a NEW file, use the "#### FILE:" format with the full content

```
